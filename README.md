Cyber Security Project 2 - Basic Encryption & Decryption

Objective

This project implements a simple encryption and decryption technique using the Caesar Cipher algorithm. The goal is to understand basic cryptography concepts and data confidentiality.

Features

- Encrypts user-entered text
- Decrypts the encrypted text
- Uses a user-defined shift value
- Preserves uppercase and lowercase letters

Technologies Used

- Python 3

How It Works

1. User enters a message.
2. User enters a shift value.
3. The program encrypts the message using the Caesar Cipher.
4. The encrypted text is displayed.
5. The program decrypts the encrypted text back to the original message.

Sample Output

Enter a message: HELLO

Enter shift value: 3

Encrypted Text: KHOOR

Decrypted Text: HELLO

Learning Outcomes

- Understanding basic encryption and decryption
- Working with strings and ASCII values
- Implementing cybersecurity fundamentals
